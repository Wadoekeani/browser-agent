## Зачем

- **Работает прямо на той странице, где вы находитесь.** Составляйте сводку, извлекайте таблицу, заполняйте форму или переходите по нескольким страницам — без копирования и вставки в отдельную вкладку чата.
- **Используйте свою модель.** Anthropic, OpenAI, Gemini, OpenRouter или что угодно, говорящее на языке API OpenAI — включая Ollama, LM Studio и vLLM на вашем компьютере.
- **Без сервера-посредника.** Запросы идут напрямую из вашего браузера к выбранному вами провайдеру. Ваш ключ, чаты и память хранятся в `chrome.storage.local`. Никакой аналитики, никакого аккаунта.
- **Рискованные действия ждут вашего подтверждения.** Клики и отправки форм, которые выглядят необратимыми, останавливаются, пока вы не нажмёте *Разрешить* на боковой панели. Эта проверка обеспечивается кодом расширения, а не просьбой к модели.

## Возможности

**Действия на странице**
- Инструменты: читать страницу, кликать, вводить текст (включая выпадающие списки `<select>`), прокручивать, открывать URL. Модель получает нумерованный список интерактивных элементов и кликает `ref: 12` вместо угадывания CSS-селекторов.
- Выделите текст на странице и спрашивайте только о нём; выделение прикрепляется к вашему сообщению вместо всей вкладки.
- PDF: текст извлекается с помощью pdf.js. Встроенный просмотрщик позволяет выделять текст в PDF так же, как на любой странице. Сканированные PDF (без текстового слоя) можно отправить в Anthropic как документ после подтверждения стоимости.

**В разговоре**
- Потоковые ответы в Markdown с таблицами и блоками кода, а также сворачиваемые сводки рассуждений (Anthropic).
- Карточки с вопросами (`ask_user`): когда модели нужно решение, она спрашивает с кликабельными вариантами вместо угадывания.
- Карточки файлов: результаты в виде скачиваемых файлов `csv`, `json`, `md`, `txt`, `tsv`, `xml`, `yaml`, `ics` или `vcf`, с копированием и предпросмотром.
- Каждый ответ показывает расход токенов; каждая задача останавливается после 30 шагов инструментов.

**Остаётся у вас**
- Память: скажите «запомни …», и агент будет хранить краткие факты о вас между чатами. Просматривайте, редактируйте или отключайте в настройках.
- История: последние 30 разговоров, сгруппированные по дате. Откройте любой и продолжайте, либо экспортируйте в Markdown.
- 12 встроенных skill и команд `/`; пишите свои в том же формате `SKILL.md`, что и Claude Code.
- Интерфейс на 15 языках; светлая и тёмная темы следуют настройкам системы.

## Быстрый старт

Browser Agent пока нет в Chrome Web Store (скоро появится). А пока установите сборку релиза — Node.js и сборка не нужны. Требуется Chrome 122+.

1. Скачайте `browser-agent-<version>.zip` из [последнего релиза](https://github.com/Wadoekeani/browser-agent/releases/latest) и распакуйте его.
2. Откройте `chrome://extensions` и включите **Режим разработчика** (в правом верхнем углу).
3. Нажмите **Загрузить распакованное расширение** и выберите распакованную папку.
4. Нажмите на значок на панели инструментов, чтобы открыть боковую панель, согласитесь с кратким уведомлением о данных, выберите провайдера и вставьте ключ (или локальный адрес).

Чтобы обновиться, скачайте новый zip-архив, замените содержимое той же папки и нажмите значок перезагрузки на карточке расширения. Ваши настройки, чаты и память сохранятся. Загрузка из другой папки установит отдельную копию, которая начнётся с пустого состояния.

### Сборка из исходного кода

Нужен Node.js 22+.

```bash
git clone https://github.com/Wadoekeani/browser-agent.git
cd browser-agent
npm ci
npm run build
```

Затем загрузите папку `extension/` через **Загрузить распакованное расширение**, как в шаге 3.

## Провайдеры

| Провайдер | Что нужно | Примечания |
|---|---|---|
| Anthropic | [API-ключ](https://console.anthropic.com/settings/keys) | Sonnet 5, Opus 5, Haiku 4.5; выбор уровня усилий; сводки рассуждений; сканированные PDF |
| OpenAI | [API-ключ](https://platform.openai.com/api-keys) | Список моделей запрашивается у провайдера |
| Google Gemini | [API-ключ](https://aistudio.google.com/apikey) | Использует совместимый с OpenAI endpoint Gemini |
| OpenRouter | [API-ключ](https://openrouter.ai/keys) | Любая модель на OpenRouter с поддержкой инструментов |
| Свой (совместимый с OpenAI) | Базовый URL, ключ опционален | Ollama, LM Studio, vLLM, llama.cpp — всё, что поддерживает `/chat/completions` |

Локальные серверы по умолчанию блокируют расширения браузера:

- **Ollama:** установите `OLLAMA_ORIGINS=chrome-extension://*` и перезапустите Ollama (macOS: `launchctl setenv OLLAMA_ORIGINS "chrome-extension://*"`). Базовый URL `http://localhost:11434/v1`.
- **LM Studio:** запустите сервер с включённым CORS, `lms server start --cors`. Базовый URL `http://localhost:1234/v1`.

Выбирайте модель, поддерживающую вызов инструментов; без этого агент не сможет действовать на странице. Использование оплачивается вашему провайдеру; расширение бесплатно.

## Skill

Введите `/` в поле сообщения, чтобы выбрать skill, или дайте модели загрузить подходящую самой.

| Команда | Что делает |
|---|---|
| `/summarize` | Краткий вывод в одну строку, ключевые пункты и задачи по текущей странице |
| `/translate` | Переводит страницу на ваш язык, сохраняя заголовки и абзацы |
| `/extract` | Извлекает данные страницы в таблицу Markdown; файл CSV или JSON, если данных много |
| `/compare` | Строит сравнительную таблицу цен, тарифов или характеристик и выделяет различия |
| `/explain` | Объясняет страницу, термин или фрагмент кода простыми словами |
| `/thread` | Подводит итог обсуждения: основные аргументы, позиции сторон, консенсус, комментарии, которые стоит прочитать |
| `/reply` | Составляет черновик ответа на письмо или сообщение на странице; может заполнить поле ответа, но никогда не отправляет |
| `/fill-form` | Заполняет форму вашими данными; спрашивает о недостающем, останавливается перед отправкой |
| `/review-pr` | Проверяет pull request на GitHub и перечисляет проблемы по степени серьёзности, с файлом и строкой |
| `/checklist` | Превращает туториал в чек-лист шагов |
| `/decide` | Раскладывает варианты, по очереди спрашивает о ваших потребностях, затем рекомендует один |
| `/grill-me` | Проверяет ваш план (или предложение на странице) вопросами с выбором ответа, по одному за раз |

`/clear` начинает новый разговор.

### Напишите свою

Skill — это файл Markdown с фронтматтером `name` и `description`, за которым следуют инструкции:

```markdown
---
name: meeting-notes
description: Turn a meeting page into decisions, action items and owners
---

1. Read the whole page with read_page.
2. List decisions, then a table of action items with owner and due date.
```

Управляйте skill в **Настройки → Навыки**: создавайте, редактируйте, импортируйте файлы `.md`, экспортируйте. Файлы `SKILL.md` из Claude Code импортируются как есть. Необязательная строка `model:` (например, `model: haiku`) запускает эту skill на более дешёвой модели Claude при использовании Anthropic.

В системный промпт попадают только названия и описания; модель вызывает `use_skill`, чтобы загрузить полные инструкции, когда они нужны, а ввод `/имя` прикрепляет их напрямую. Skill — это промпты — прочитайте её перед импортом.

## Безопасность и конфиденциальность

**Поток данных.** Ваш браузер общается только с одним местом: провайдером или endpoint, который вы настроили. Запрос содержит ваши сообщения, содержимое страницы, которое прочитал агент (или только ваше выделение, или PDF), сохранённую память и названия ваших skill. Ваш API-ключ, разговоры, память и skill хранятся только в `chrome.storage.local`. Сервера Browser Agent не существует, аналитики нет, удалённого кода нет. Ничего не отправляется, пока вы не согласитесь с уведомлением о данных при первом запуске. Подробности: [политика конфиденциальности](store/privacy-policy.md).

**Что требует вашего *Разрешить*.** Эти действия показывают карточку на боковой панели и не выполняются, пока вы не нажмёте *Разрешить*. Карточка находится на собственной странице расширения, которую сайт не может кликнуть за вас:

- клики и отправки форм, которые выглядят необратимыми: видимый текст кнопки, `aria-label`, title или value читаются как «оплатить», «купить», «заказать», «удалить», «отправить», «опубликовать», «авторизовать», «сохранить», «поделиться», «установить» и похожие (на всех 15 языках интерфейса); форма с несколькими полями или полем пароля; кнопка только с иконкой внутри формы; нажатие Enter в поле не внутри формы (чат-окна). Если видимый текст кнопки и её `aria-label` расходятся, карточка предупреждает вас;
- переход на другой сайт, через навигацию или клик по ссылке, если это не тот сайт, с которого началась задача, сайт, названный вами в сообщении, или уже разрешённый в этой задаче. Карточка показывает полный URL, включая строку запроса;
- сохранение памяти, если разговор уже содержит веб-контент (прочитанную страницу, PDF, выделение).

Клик по подсказке сразу отправляет её. Подсказки, сгенерированные на основе страницы, пишутся после чтения её содержимого, поэтому страница может на них повлиять: упомянутые в них сайты не считаются названными вами, а всё, что они запускают, всё равно проходит через те же карточки подтверждения. Ссылки в ответах показывают свой настоящий домен рядом с текстом.

**Вывод и файлы.** Ответы модели рендерятся с помощью DOMPurify. Изображения, медиа, SVG, iframe, формы и inline-стили удаляются, так что страница не может заставить модель слить вашу переписку через URL изображения. Генерируемые файлы — только текстовые форматы (`csv`, `json`, `md`, …), а ячейки CSV/TSV, начинающиеся как формула электронной таблицы, нейтрализуются.

### Известные ограничения

- **Проблема prompt injection не решена.** Агент читает и действует на сайтах с вашей авторизованной сессией. Вредоносная страница может попытаться направить его на отправку вашей переписки, памяти или данных с других сайтов куда-либо, либо заставить его действовать за вас. Карточки подтверждения покрывают перечисленные выше действия высокого риска; это не полная защита.
- Не используйте расширение на непроверенных страницах, пока открыты вкладки с банком, почтой или админкой компании, и следите за ним во время выполнения задачи.
- Обнаружение рискованных кликов — это эвристика по ключевым словам и форме формы. Некоторые кнопки будут пропущены.
- Ввод текста в поле на том же сайте не запрашивает подтверждение. Вредоносная страница может прочитать, что вводит агент (например, через слушатель `input`), и отправить это на свой сервер.
- Импортированный `SKILL.md` — это доверенные инструкции. Импортируйте только те skill, которые вы прочитали.
- Память и разговоры хранятся в браузере в незашифрованном виде и отправляются выбранному вами провайдеру в составе каждого запроса.
- Каждая задача останавливается после 30 шагов инструментов, и каждый ответ показывает расход токенов, поэтому вышедший из-под контроля цикл ограничен и заметен.

## Разработка

```bash
npm run watch      # rebuild on save; then click reload on the extension card
npm run typecheck  # tsc --noEmit
npm run check      # unit self-checks: skills, memory, history, files, providers, i18n
npm run test:e2e   # builds, loads the extension in Playwright against mocked model APIs
```

Боковая панель — это React + TypeScript, собранный esbuild в `extension/`. Бэкенда нет: `src/agent.ts` выполняет цикл агента на боковой панели, вызывая Anthropic через официальный SDK или любой совместимый с OpenAI API через `src/providers.ts`. Инструменты в `src/tools.ts` выполняются на активной вкладке через `chrome.scripting`; `src/elements.ts` строит нумерованный список элементов и проверку необратимых действий. Набор e2e-тестов не требует API-ключа и ничего не стоит.

| Путь | Что это |
|---|---|
| `src/sidepanel.tsx` | Точка входа и основной интерфейс (онбординг, чат, поле ввода, меню `/`) |
| `src/agent.ts` | Цикл агента, загрузка настроек, skill по умолчанию, сохранение/восстановление истории |
| `src/providers.ts` | Список провайдеров и адаптер, совместимый с OpenAI |
| `src/tools.ts` | Реализации инструментов (`runTool`) и шлюз подтверждения |
| `src/shared.ts` | Системный промпт и определения инструментов |
| `src/elements.ts` | Нумерованные интерактивные элементы (`data-ba` refs) и проверка риска |
| `src/log.tsx` | Журнал чата, карточки, рендеринг Markdown с DOMPurify |
| `src/pages.tsx` | Настройки, история и редактор skill |
| `src/pdf.ts`, `src/viewer.ts` | Извлечение текста из PDF и встроенный просмотрщик |
| `src/selection.ts` | Чип выделенного текста |
| `src/skills.ts`, `src/memory.ts`, `src/history.ts`, `src/files.ts` | Парсинг `SKILL.md`, память, история, карточки файлов |
| `src/i18n/` | `t()` и 15 словарей (`en.ts` — источник истины) |
| `extension/` | Манифест, `_locales/`, HTML, service worker — загружайте эту папку в Chrome |

Чтобы добавить инструмент: добавьте его схему в `tools` в `src/shared.ts` и `case` в `runTool` в `src/tools.ts`.

### Перевод

Скопируйте `src/i18n/locales/en.ts` в, например, `nl.ts`, объявите его как `const nl: Dict = { … }`, переведите значения (сохраняя каждый `{placeholder}`), и добавьте его в `LANGS` и загрузчики в `src/i18n/index.ts`. `npm run typecheck` завершится ошибкой при отсутствующем или лишнем ключе; `npm run check` — при несовпадающем placeholder. Промпты и описания инструментов, отправляемые модели, намеренно остаются на одном языке. Для названия и описания в Chrome Web Store добавьте `extension/_locales/<code>/messages.json` (Chrome использует подчёркивания, например, `pt_BR`).
