## ทำไมต้องใช้

- **ทำงานบนหน้าเว็บที่คุณเปิดอยู่ได้ทันที** สรุปเนื้อหา ดึงข้อมูลเป็นตาราง กรอกฟอร์ม หรือคลิกไล่ไปทีละหน้า — โดยไม่ต้องคัดลอกวางไปที่แท็บแชท
- **ใช้โมเดลของคุณเองได้** Anthropic, OpenAI, Gemini, OpenRouter หรืออะไรก็ได้ที่รองรับ OpenAI API — รวมถึง Ollama, LM Studio และ vLLM บนเครื่องของคุณเอง
- **ไม่มีเซิร์ฟเวอร์คั่นกลาง** คำขอส่งตรงจากเบราว์เซอร์ของคุณไปยังผู้ให้บริการที่คุณเลือก คีย์ บทสนทนา และความทรงจำของคุณจะอยู่ใน `chrome.storage.local` เท่านั้น ไม่มีการเก็บข้อมูลวิเคราะห์ ไม่ต้องมีบัญชี
- **การกระทำที่มีความเสี่ยงจะรอให้คุณอนุญาตก่อน** การคลิกหรือส่งฟอร์มที่ดูเหมือนย้อนกลับไม่ได้จะหยุดรอจนกว่าคุณจะกด *อนุญาต* ในไซด์พาเนล การตรวจสอบนี้บังคับใช้โดยโค้ดของส่วนขยายเอง ไม่ใช่แค่การขอร้องโมเดลเฉยๆ

## ฟีเจอร์

**การทำงานบนหน้าเว็บ**
- เครื่องมือ: อ่านหน้าเว็บ คลิก พิมพ์ (รวมถึงดรอปดาวน์ `<select>`) เลื่อนหน้า เปิด URL โมเดลจะได้รับรายการองค์ประกอบที่โต้ตอบได้แบบมีหมายเลข และคลิกด้วย `ref: 12` แทนการเดา CSS selector
- เลือกข้อความบนหน้าเว็บแล้วถามเฉพาะเรื่องนั้น ส่วนที่เลือกจะถูกแนบไปกับข้อความของคุณแทนที่จะเป็นทั้งแท็บ
- PDF: ดึงข้อความด้วย pdf.js ตัวแสดงผลในตัวช่วยให้คุณเลือกข้อความในไฟล์ PDF ได้เหมือนหน้าเว็บทั่วไป ไฟล์ PDF ที่สแกนมา (ไม่มีเลเยอร์ข้อความ) สามารถส่งไปยัง Anthropic เป็นเอกสารได้ หลังจากคุณยืนยันค่าใช้จ่ายแล้ว

**ในบทสนทนา**
- ตอบกลับแบบ Markdown สตรีมมิงพร้อมตารางและบล็อกโค้ด รวมถึงสรุปกระบวนการคิดที่ย่อ/ขยายได้ (Anthropic)
- การ์ดคำถาม (`ask_user`): เมื่อโมเดลต้องการการตัดสินใจ มันจะถามพร้อมตัวเลือกที่คลิกได้แทนการเดา
- การ์ดไฟล์: ผลลัพธ์เป็นไฟล์ที่ดาวน์โหลดได้ในรูปแบบ `csv`, `json`, `md`, `txt`, `tsv`, `xml`, `yaml`, `ics` หรือ `vcf` พร้อมปุ่มคัดลอกและดูตัวอย่าง
- ทุกการตอบกลับแสดงปริมาณการใช้โทเคน แต่ละงานจะหยุดหลังจากใช้เครื่องมือครบ 30 ขั้นตอน

**เก็บไว้เป็นของคุณ**
- ความทรงจำ: พิมพ์ "จำไว้ว่า …" แล้วมันจะเก็บข้อเท็จจริงสั้นๆ เกี่ยวกับคุณไว้ข้ามบทสนทนา ดู แก้ไข หรือปิดได้ในการตั้งค่า
- ประวัติ: 30 บทสนทนาล่าสุด จัดกลุ่มตามวันที่ เปิดต่อจากเดิมได้ หรือส่งออกเป็น Markdown
- สกิลในตัว 12 รายการและคำสั่ง `/`; เขียนสกิลของคุณเองด้วยรูปแบบ `SKILL.md` แบบเดียวกับ Claude Code
- อินเทอร์เฟซรองรับ 15 ภาษา; ธีมสว่างและมืดจะตามระบบของคุณ

## เริ่มต้นใช้งานอย่างรวดเร็ว

Browser Agent ยังไม่มีบน Chrome Web Store (เร็วๆ นี้) ระหว่างนี้ให้ติดตั้งจากไฟล์ build ที่เผยแพร่ — ไม่ต้องใช้ Node.js หรือขั้นตอนบิลด์ใดๆ ต้องใช้ Chrome 122 ขึ้นไป

1. ดาวน์โหลด `browser-agent-<version>.zip` จาก[รีลีสล่าสุด](https://github.com/Wadoekeani/browser-agent/releases/latest) แล้วแตกไฟล์
2. เปิด `chrome://extensions` แล้วเปิด **Developer mode** (โหมดสำหรับนักพัฒนาซอฟต์แวร์ มุมขวาบน)
3. คลิก **Load unpacked** (โหลดส่วนขยายที่ยังไม่ได้แพ็กเกจ) แล้วเลือกโฟลเดอร์ที่แตกไฟล์ไว้
4. คลิกไอคอนบนแถบเครื่องมือเพื่อเปิดไซด์พาเนล ยอมรับประกาศเกี่ยวกับข้อมูลแบบสั้นๆ เลือกผู้ให้บริการ และวางคีย์ (หรือ endpoint ภายในเครื่อง)

หากต้องการอัปเดต ให้ดาวน์โหลดไฟล์ zip ใหม่ แทนที่เนื้อหาในโฟลเดอร์เดิม แล้วคลิกไอคอนรีโหลดบนการ์ดส่วนขยาย การตั้งค่า บทสนทนา และความทรงจำของคุณจะยังอยู่ครบ การโหลดจากโฟลเดอร์อื่นจะติดตั้งเป็นชุดแยกที่เริ่มต้นแบบว่างเปล่า

### Build จากซอร์สโค้ด

คุณต้องมี Node.js 22 ขึ้นไป

```bash
git clone https://github.com/Wadoekeani/browser-agent.git
cd browser-agent
npm ci
npm run build
```

จากนั้นโหลดโฟลเดอร์ `extension/` ด้วย **Load unpacked** เหมือนในขั้นตอนที่ 3

## ผู้ให้บริการ

| ผู้ให้บริการ | สิ่งที่คุณต้องมี | หมายเหตุ |
|---|---|---|
| Anthropic | [API key](https://console.anthropic.com/settings/keys) | Sonnet 5, Opus 5, Haiku 4.5; ตัวเลือกระดับ effort; สรุปกระบวนการคิด; PDF ที่สแกนมา |
| OpenAI | [API key](https://platform.openai.com/api-keys) | รายชื่อโมเดลดึงมาจากผู้ให้บริการ |
| Google Gemini | [API key](https://aistudio.google.com/apikey) | ใช้ endpoint ของ Gemini ที่รองรับ OpenAI |
| OpenRouter | [API key](https://openrouter.ai/keys) | โมเดลใดก็ได้บน OpenRouter ที่รองรับ tool calling |
| กำหนดเอง (รองรับ OpenAI) | Base URL, คีย์ไม่บังคับ | Ollama, LM Studio, vLLM, llama.cpp — อะไรก็ได้ที่มี `/chat/completions` |

เซิร์ฟเวอร์ภายในเครื่องจะบล็อกส่วนขยายเบราว์เซอร์โดยค่าเริ่มต้น:

- **Ollama:** ตั้งค่า `OLLAMA_ORIGINS=chrome-extension://*` แล้วรีสตาร์ท Ollama (macOS: `launchctl setenv OLLAMA_ORIGINS "chrome-extension://*"`) Base URL คือ `http://localhost:11434/v1`
- **LM Studio:** เปิดเซิร์ฟเวอร์โดยเปิด CORS ด้วยคำสั่ง `lms server start --cors` Base URL คือ `http://localhost:1234/v1`

เลือกโมเดลที่รองรับ tool calling เพราะเอเจนต์ไม่สามารถทำงานบนหน้าเว็บได้หากไม่มีสิ่งนี้ ค่าใช้บริการจะถูกเรียกเก็บโดยผู้ให้บริการของคุณ ส่วนตัวส่วนขยายเองใช้งานฟรี

## สกิล

พิมพ์ `/` ในช่องพิมพ์ข้อความเพื่อเลือกสกิล หรือปล่อยให้โมเดลโหลดเองเมื่อเหมาะสม

| คำสั่ง | สิ่งที่ทำ |
|---|---|
| `/summarize` | สรุปสั้นๆ หนึ่งบรรทัด ประเด็นสำคัญ และสิ่งที่ต้องทำต่อจากหน้าปัจจุบัน |
| `/translate` | แปลหน้าเว็บเป็นภาษาของคุณ โดยคงโครงสร้างหัวข้อและย่อหน้าไว้ |
| `/extract` | ดึงข้อมูลบนหน้าเว็บมาเป็นตาราง Markdown; เป็นไฟล์ CSV หรือ JSON เมื่อข้อมูลมีจำนวนมาก |
| `/compare` | สร้างตารางเปรียบเทียบราคา แพ็กเกจ หรือสเปก และเน้นความแตกต่าง |
| `/explain` | อธิบายหน้าเว็บ คำศัพท์ หรือโค้ดบางส่วนด้วยภาษาที่เข้าใจง่าย |
| `/thread` | สรุปกระทู้คอมเมนต์: ข้อโต้แย้งหลัก แต่ละฝ่าย ความเห็นตรงกัน คอมเมนต์ที่น่าอ่าน |
| `/reply` | ร่างคำตอบสำหรับอีเมลหรือข้อความบนหน้าเว็บ; สามารถกรอกในช่องตอบกลับได้ แต่ไม่ส่งเอง |
| `/fill-form` | กรอกฟอร์มด้วยข้อมูลของคุณ; ถามหาข้อมูลที่ขาด และหยุดก่อนส่ง |
| `/review-pr` | ตรวจสอบ pull request บน GitHub และแสดงรายการปัญหาตามระดับความรุนแรง พร้อมไฟล์และบรรทัด |
| `/checklist` | เปลี่ยนบทช่วยสอนให้เป็นเช็คลิสต์ขั้นตอน |
| `/decide` | เรียงลำดับตัวเลือกทั้งหมด ถามความต้องการของคุณทีละข้อ แล้วแนะนำตัวเลือกหนึ่ง |
| `/grill-me` | ทดสอบแผนของคุณ (หรือข้อเสนอบนหน้าเว็บ) ด้วยคำถามปรนัยทีละข้อ |

`/clear` เริ่มบทสนทนาใหม่

### เขียนสกิลของคุณเอง

สกิลคือไฟล์ Markdown ที่มี frontmatter `name` และ `description` ตามด้วยคำสั่ง:

```markdown
---
name: meeting-notes
description: Turn a meeting page into decisions, action items and owners
---

1. Read the whole page with read_page.
2. List decisions, then a table of action items with owner and due date.
```

จัดการสกิลได้ที่ **Settings → Skills** (การตั้งค่า → สกิล): สร้าง แก้ไข นำเข้าไฟล์ `.md` ส่งออก ไฟล์ `SKILL.md` ของ Claude Code นำเข้าได้โดยตรง บรรทัด `model:` ที่ไม่บังคับ (เช่น `model: haiku`) จะสั่งให้สกิลนั้นทำงานบนโมเดล Claude ที่ถูกกว่าเมื่อคุณใช้ Anthropic

มีเพียงชื่อและคำอธิบายเท่านั้นที่ถูกใส่ใน system prompt; โมเดลจะเรียก `use_skill` เพื่อโหลดคำสั่งฉบับเต็มเมื่อจำเป็น และการพิมพ์ `/ชื่อ` จะแนบคำสั่งนั้นเข้ามาโดยตรง สกิลคือพรอมต์ — อ่านให้ครบก่อนนำเข้า

## ความปลอดภัยและความเป็นส่วนตัว

**การไหลของข้อมูล** เบราว์เซอร์ของคุณจะสื่อสารกับที่เดียวเท่านั้น: ผู้ให้บริการหรือ endpoint ที่คุณตั้งค่าไว้ คำขอหนึ่งครั้งประกอบด้วยข้อความของคุณ เนื้อหาหน้าเว็บที่เอเจนต์อ่าน (หรือเฉพาะส่วนที่คุณเลือก หรือไฟล์ PDF) ความทรงจำที่บันทึกไว้ และชื่อสกิลของคุณ คีย์ API บทสนทนา ความทรงจำ และสกิลของคุณจะถูกเก็บไว้ใน `chrome.storage.local` เท่านั้น ไม่มีเซิร์ฟเวอร์ของ Browser Agent ไม่มีการเก็บข้อมูลวิเคราะห์ และไม่มีโค้ดจากระยะไกล จะไม่มีการส่งข้อมูลใดๆ ก่อนที่คุณจะยอมรับประกาศเกี่ยวกับข้อมูลในการใช้งานครั้งแรก รายละเอียดทั้งหมด: [นโยบายความเป็นส่วนตัว](store/privacy-policy.md)

**สิ่งที่ต้องให้คุณ *อนุญาต*** การกระทำเหล่านี้จะแสดงการ์ดในไซด์พาเนลและจะไม่ทำงานจนกว่าคุณจะกด *อนุญาต* การ์ดนี้อยู่ในหน้าของส่วนขยายเอง ซึ่งเว็บไซต์ไม่สามารถคลิกแทนคุณได้:

- การคลิกและการส่งฟอร์มที่ดูเหมือนย้อนกลับไม่ได้: ข้อความที่มองเห็นบนปุ่ม, `aria-label`, title หรือ value ที่อ่านแล้วคล้ายกับ จ่ายเงิน ซื้อ สั่งซื้อ ลบ ส่ง เผยแพร่ อนุญาตสิทธิ์ บันทึก แชร์ ติดตั้ง และคำอื่นๆ ในลักษณะเดียวกัน (ในทั้ง 15 ภาษาของอินเทอร์เฟซ); ฟอร์มที่มีหลายช่องหรือมีช่องรหัสผ่าน; ปุ่มที่มีแต่ไอคอนภายในฟอร์ม; การกด Enter ในช่องที่ไม่ได้อยู่ในฟอร์ม (เช่นกล่องแชท) หากข้อความที่มองเห็นบนปุ่มกับ `aria-label` ไม่ตรงกัน การ์ดจะแจ้งเตือนคุณ
- การไปยังเว็บไซต์อื่น ไม่ว่าจะโดยการนำทางหรือคลิกลิงก์ เว้นแต่จะเป็นเว็บไซต์ที่เริ่มงานนี้ เว็บไซต์ที่คุณระบุไว้ในข้อความของคุณ หรือเว็บไซต์ที่คุณอนุญาตไปแล้วในงานนี้ การ์ดจะแสดง URL แบบเต็ม รวมถึง query string ด้วย
- การบันทึกความทรงจำ เมื่อบทสนทนามีเนื้อหาจากเว็บ (หน้าเว็บที่อ่าน, PDF, หรือข้อความที่เลือก)

การคลิกคำแนะนำจะส่งออกไปทันที คำแนะนำที่สร้างจากหน้าเว็บนั้นเขียนขึ้นหลังจากอ่านเนื้อหาหน้าเว็บแล้ว ดังนั้นหน้าเว็บสามารถมีอิทธิพลต่อคำแนะนำได้: เว็บไซต์ที่ถูกกล่าวถึงในคำแนะนำนั้นไม่นับว่าเป็นเว็บไซต์ที่คุณระบุเอง และสิ่งที่มันกระตุ้นให้เกิดขึ้นก็ยังต้องผ่านการ์ดยืนยันเดียวกัน ลิงก์ในคำตอบจะแสดงโดเมนจริงไว้ข้างข้อความ

**เอาต์พุตและไฟล์** คำตอบของโมเดลจะถูกเรนเดอร์ด้วย DOMPurify รูปภาพ สื่อ SVG iframe ฟอร์ม และ inline style จะถูกลบออก เพื่อไม่ให้หน้าเว็บสามารถหลอกให้โมเดลรั่วไหลบทสนทนาของคุณผ่าน URL รูปภาพได้ ไฟล์ที่สร้างขึ้นเป็นรูปแบบข้อความธรรมดาเท่านั้น (`csv`, `json`, `md`, …) และเซลล์ CSV/TSV ที่ขึ้นต้นคล้ายสูตรสเปรดชีตจะถูกทำให้เป็นกลาง

### ข้อจำกัดที่ทราบอยู่แล้ว

- **ยังไม่สามารถแก้ปัญหา prompt injection ได้อย่างสมบูรณ์** เอเจนต์อ่านและทำงานบนเว็บไซต์ด้วยเซสชันที่คุณล็อกอินอยู่ หน้าเว็บที่เป็นอันตรายอาจพยายามชักนำให้มันส่งบทสนทนา ความทรงจำ หรือข้อมูลจากเว็บไซต์อื่นไปยังที่ใดที่หนึ่ง หรือทำสิ่งต่างๆ แทนคุณ การ์ดยืนยันครอบคลุมการกระทำที่มีความเสี่ยงสูงตามที่กล่าวข้างต้น แต่ไม่ใช่การป้องกันที่สมบูรณ์
- อย่ารันบนหน้าเว็บที่ไม่น่าเชื่อถือขณะที่มีแท็บธนาคาร อีเมล หรือระบบแอดมินของบริษัทคุณเปิดอยู่ และเฝ้าดูขณะที่งานกำลังทำงาน
- การตรวจจับการคลิกที่มีความเสี่ยงใช้หลักฮิวริสติกจากคำสำคัญและรูปแบบฟอร์ม อาจพลาดปุ่มบางปุ่มไป
- การพิมพ์ในช่องบนเว็บไซต์เดียวกันจะไม่มีการถามยืนยัน หน้าเว็บที่เป็นอันตรายอาจอ่านสิ่งที่เอเจนต์พิมพ์ได้ (เช่นด้วย listener ของ `input`) แล้วส่งไปยังเซิร์ฟเวอร์ของตัวเอง
- ไฟล์ `SKILL.md` ที่นำเข้ามาถือเป็นคำสั่งที่เชื่อถือได้ ควรนำเข้าเฉพาะสกิลที่คุณอ่านแล้วเท่านั้น
- ความทรงจำและบทสนทนาจะถูกเก็บไว้แบบไม่เข้ารหัสในเบราว์เซอร์ของคุณ และถูกส่งไปยังผู้ให้บริการที่คุณเลือกเป็นส่วนหนึ่งของทุกคำขอ
- แต่ละงานจะหยุดหลังจากใช้เครื่องมือครบ 30 ขั้นตอน และทุกการตอบกลับจะแสดงปริมาณการใช้โทเคน ทำให้ลูปที่ควบคุมไม่ได้ถูกจำกัดขอบเขตและมองเห็นได้เสมอ

## ภาษา

English, 繁體中文, 简体中文, 日本語, 한국어, Español, Français, Deutsch, Português (Brasil), Italiano, Русский, Tiếng Việt, Bahasa Indonesia, ไทย, Türkçe ค่าเริ่มต้นจะเป็นไปตามเบราว์เซอร์ของคุณ เปลี่ยนได้ที่ **Settings → Language** (การตั้งค่า → ภาษา) โมเดลจะตอบเป็นภาษาของอินเทอร์เฟซคุณ เว้นแต่คุณจะเขียนเป็นภาษาอื่น

## การพัฒนา

```bash
npm run watch      # rebuild on save; then click reload on the extension card
npm run typecheck  # tsc --noEmit
npm run check      # unit self-checks: skills, memory, history, files, providers, i18n
npm run test:e2e   # builds, loads the extension in Playwright against mocked model APIs
```

ไซด์พาเนลเขียนด้วย React + TypeScript และบันเดิลด้วย esbuild ลงใน `extension/` ไม่มี backend: `src/agent.ts` รันลูปของเอเจนต์ในไซด์พาเนล เรียก Anthropic ผ่าน SDK อย่างเป็นทางการ หรือ API ที่รองรับ OpenAI ตัวใดก็ได้ผ่าน `src/providers.ts` เครื่องมือใน `src/tools.ts` ทำงานในแท็บที่ใช้งานอยู่ด้วย `chrome.scripting`; `src/elements.ts` สร้างรายการองค์ประกอบแบบมีหมายเลขและการตรวจสอบการกระทำที่ย้อนกลับไม่ได้ ชุดทดสอบ e2e ไม่ต้องใช้ API key และไม่มีค่าใช้จ่ายใดๆ

| Path | สิ่งที่ทำ |
|---|---|
| `src/sidepanel.tsx` | จุดเริ่มต้นและ UI หลัก (onboarding, แชท, ช่องพิมพ์ข้อความ, เมนู `/`) |
| `src/agent.ts` | ลูปของเอเจนต์, การโหลดการตั้งค่า, สกิลเริ่มต้น, การบันทึก/กู้คืนประวัติ |
| `src/providers.ts` | รายชื่อผู้ให้บริการและ adapter ที่รองรับ OpenAI |
| `src/tools.ts` | การทำงานของเครื่องมือ (`runTool`) และประตูยืนยัน |
| `src/shared.ts` | System prompt และคำนิยามของเครื่องมือ |
| `src/elements.ts` | องค์ประกอบที่โต้ตอบได้แบบมีหมายเลข (อ้างอิง `data-ba`) และการตรวจสอบความเสี่ยง |
| `src/log.tsx` | บันทึกแชท, การ์ด, การเรนเดอร์ Markdown ด้วย DOMPurify |
| `src/pages.tsx` | การตั้งค่า ประวัติ และตัวแก้ไขสกิล |
| `src/pdf.ts`, `src/viewer.ts` | การดึงข้อความจาก PDF และตัวแสดงผลในตัว |
| `src/selection.ts` | ชิปของข้อความที่เลือก |
| `src/skills.ts`, `src/memory.ts`, `src/history.ts`, `src/files.ts` | การแปลไฟล์ `SKILL.md`, ความทรงจำ, ประวัติ, การ์ดไฟล์ |
| `src/i18n/` | `t()` และพจนานุกรมทั้ง 15 ภาษา (`en.ts` คือต้นฉบับที่เชื่อถือได้) |
| `extension/` | Manifest, `_locales/`, HTML, service worker — โหลดโฟลเดอร์นี้ใน Chrome |

หากต้องการเพิ่มเครื่องมือ: เพิ่ม schema ของมันใน `tools` ที่ `src/shared.ts` และเพิ่ม `case` ใน `runTool` ที่ `src/tools.ts`

### การแปลภาษา

คัดลอก `src/i18n/locales/en.ts` ไปเป็นเช่น `nl.ts` ประกาศเป็น `const nl: Dict = { … }` แปลค่าต่างๆ (คงไว้ทุก `{placeholder}`) แล้วเพิ่มเข้าไปใน `LANGS` และตัวโหลดใน `src/i18n/index.ts` `npm run typecheck` จะล้มเหลวหากมีคีย์ขาดหรือเกิน; `npm run check` จะล้มเหลวหากมี placeholder ไม่ตรงกัน พรอมต์และคำอธิบายเครื่องมือที่ส่งไปยังโมเดลตั้งใจให้คงเป็นภาษาเดียวเสมอ สำหรับชื่อและคำอธิบายบน Chrome Web Store ให้เพิ่ม `extension/_locales/<code>/messages.json` (Chrome ใช้ขีดล่าง เช่น `pt_BR`)
