## 名稱（上限 75）

Browser Agent

## 摘要（上限 132，純文字；同 manifest 的 description）

在 Chrome 側邊欄的 AI 助理，能讀取並操作目前分頁。用你自己的金鑰：Claude、OpenAI、Gemini，或自架模型。

## 完整說明

Browser Agent 把 AI 助理放進 Chrome 側邊欄，它看得到你正在看的網頁，也能直接動手：摘要、抽出表格、比價、填表、翻譯……

用平常說話的方式交代就好。它會讀取目前分頁、幫你點擊、輸入、捲動、換頁，每一步都列在對話裡，做了什麼一目了然。

自備模型
填入你自己的 API 金鑰：Claude（Anthropic）、OpenAI、Google Gemini、OpenRouter，或任何 OpenAI 相容端點，包括你自己架的模型（Ollama、LM Studio、vLLM）。請求從你的瀏覽器直接送到你選的供應商，中間沒有 Browser Agent 的伺服器，用量由供應商向你計費。

主控權在你手上
遇到看起來無法復原的動作（付款、下單、刪除、送出表單），擴充功能本身會先停下來，等你按「允許」。網頁內容沒辦法說服模型跳過這一步。每個任務最多 30 步，每則回覆都會顯示用了多少 token。

功能
• 網頁操作：讀取頁面、點擊、輸入（含下拉選單）、捲動、開啟網頁
• 選取文字：選一段網頁內容，就只針對這段問，不用整頁都讀
• PDF 閱讀：開啟 PDF 直接問，連沒有文字層的掃描檔也讀得到（會以圖片整份送給 Anthropic，但一定先問過你，見下方隱私說明）
• 12 個內建技能，輸入 / 就能選：/summarize、/translate、/extract、/compare、/explain、/thread、/reply、/fill-form、/review-pr、/checklist、/decide、/grill-me
• 用 Markdown 寫自己的技能（SKILL.md 檔可直接匯入）
• 選擇卡片：需要你決定時，會列出選項讓你點選
• 檔案下載：結果可以存成 CSV、Markdown、JSON 等純文字檔
• 記憶：說「記住……」，它會記下關於你的簡短事實，可在設定裡檢視、修改或關閉
• 歷史對話：最近 30 則對話存在你的電腦上，可以打開接著聊，或匯出成 Markdown
• 首頁會依目前頁面給建議（預設關閉，可在設定裡打開）
• 淺色／深色主題，介面支援 15 種語言

隱私
API 金鑰、對話、記憶與技能只存在你的瀏覽器裡（chrome.storage.local）。沒有分析、沒有追蹤、不用註冊帳號。頁面內容、選取文字與 PDF 只會送到你選的模型供應商，用來回應你的要求。第一次使用前，擴充功能會先說明這件事並請你同意才能開始。完整隱私權政策：https://github.com/Wadoekeani/browser-agent/blob/main/store/privacy-policy.md

## 常見問題

**要付費嗎？**
擴充功能免費。模型用量用你自己的 API 金鑰付給供應商；如果在本機跑模型，就完全不用錢。

**會送出哪些資料？送給誰？**
你提出要求時，相關的頁面內容（或你選取的文字、你正在讀的 PDF）和對話會送到你選的模型供應商（或你自己的端點）。沒有文字層的掃描 PDF，只有在你按下確認卡片的「允許」之後，才會以圖片整份送給 Anthropic。如果你打開首頁建議（預設關閉），在新對話打開側邊欄也會把頁面的標題、網址與開頭約 800 字送給該供應商。我們不會收到任何資料——根本沒有 Browser Agent 的伺服器。

**它會自己買東西或刪東西嗎？**
不會先斬後奏。以下動作都要等你在側邊欄按「允許」，卡片上會寫清楚要做什麼：看起來無法復原的點擊（付款、購買、刪除、送出、授權、傳送、發佈、分享等 15 種語言的常見字，同時比對按鈕上看得到的字、無障礙標籤、title 與 value，兩者不一致時會警告）；表單裡或有密碼欄的頁面上沒有文字的圖示按鈕；不在表單裡的輸入框按 Enter 送出（聊天、留言框）；有多個欄位或含密碼的表單；前往開始時的網站與你訊息裡提到的網站以外的地方（卡片顯示完整網址，因為網址本身就能把資料帶出去）；以及對話讀過網頁內容之後要寫入記憶。首頁建議只會填進輸入框，要你自己按送出。

限制：這是一組規則，不是百分之百保證。在同一個網站內輸入文字不會問你，所以惡意網頁看得到它在那個網站輸入的內容；惡意網頁也可能用不符合上述規則的方式誘導模型。在敏感網站上請多留意它在做什麼。
